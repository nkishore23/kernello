# KERNELLO nut shop

1. Copy your 10 videos into `public/video/` with EXACT names:
   hero-almond, hero-cashew, hero-pistachio, hero-walnut, hero-hazelnut,
   story-1-orchard, story-2-crack, story-3-roast, story-4-pack, jar-pour  (all .mp4)
2. `npm install`
3. `npm run dev`  -> open the URL shown (also works on phone via the Network URL)
4. Edit brand name, WhatsApp number, prices, nuts: `src/data.js`
5. Deploy: `npm run build` then upload `dist/` to Netlify / Vercel.

## Deploy on Vercel
Push to GitHub -> vercel.com -> Import -> Framework: Vite (auto) -> Deploy.
Build command: `npm run build`  Output: `dist`
